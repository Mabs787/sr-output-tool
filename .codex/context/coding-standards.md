# Coding Standards

- Preserve raw VoiceOver evidence as the primary source of truth.
- Do not reshape valid VoiceOver output to match the current engine.
- Do not add site-specific engine logic.
- Prefer reusable DOM, AX, role, state, traversal, or announcement rules.
- Keep fixture edits evidence-backed and documented in agent receipts.
- Preserve unrelated user changes in the working tree.
- Add focused unit coverage when a reusable behavior changes.
- Rebuild the extension runtime whenever engine output behavior changes.
