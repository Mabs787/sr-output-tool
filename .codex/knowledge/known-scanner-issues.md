# Known Scanner Issues

- Captions and OCR can introduce spacing, punctuation, casing, and character confusion.
- Step snapshots may preserve dynamic UI state that differs from a later engine comparison.
- Open menus, consent dialogs, and carousels can create page-backed output that looks noisy but is real for that scan.
- Missing source evidence should block exact promotion unless HTML, AX, and snapshots are enough to prove the announcement.
